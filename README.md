CarCareHub React UI
===================
Run locally:
1. Install Node.js (18+ recommended).
2. Extract this ZIP and open the folder in VS Code.
3. Run: npm install
4. Run: npm run dev
5. Open the localhost URL printed by Vite.

Built with React + Vite + plain CSS + lucide-react.
Screens: Dashboard, Customers, Vehicles, Service Jobs, Spare Parts, Stock Movements,
Invoices, Payments, Expenses, Service Reminders, Notifications, Reports, Settings.

This is a UI prototype with demo data. It is not connected to the Spring Boot backend yet.
